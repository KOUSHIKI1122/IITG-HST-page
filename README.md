## About

A redesign of the web page for the **Jyoti & Bhupat Mehta School of Health Sciences & Technology (JBMSHST), IIT Guwahati**. It is a single-file, no-framework site that brings the school's key information (admissions, faculty, news, research and resources) into one friendly page, built in two visual styles.

## Two designs

| | 🎮 Arcade | 🏛️ Formal |
|---|---|---|
| **Style** | Pixel-art, retro-game UI | Clean, professional palette |
| **Fonts** | Press Start 2P, VT323, Quicksand | Professional serif/sans pairing |
| **Live** | [jbmshst.netlify.app](https://jbmshst.netlify.app/) | [biomed-jbmshst.netlify.app](https://biomed-jbmshst.netlify.app/) |
| **File** | `arcade.html` | `formal.html` |

## Features

- 📢 Scrolling notice ticker with clickable announcements
- 🎓 Admissions panel with Ph.D., GATE and MoU tabs
- 📰 Tabbed publications, news and events cards
- 👩‍🔬 Faculty cards with email and Scholar links
- 🗓️ Academic-cycle timeline selector
- 🔗 Quick-access tiles and a full footer of student and research resources
- 📱 Responsive layout

## Run locally

```bash
git clone https://github.com/KOUSHIKI1122/IITG-HST-page.git
cd IITG-HST-page
```

Open `arcade.html` or `formal.html` in any browser. No build step or dependencies.

## Deployment

Both pages are hosted on Netlify. Any file named `index.html` is served as the homepage.

## ⚠️ Note

Content is based on the official [JBMSHST site](https://www.iitg.ac.in/shst/index.php). Always confirm admission dates and notices on the official portal.
